# 120 秒实际产品演示脚本

**状态：脚本已准备，视频未录制。** 当前受控浏览器只提供截图与交互，没有录屏能力；未用截图合成冒充操作视频。当前 Groq 日额度受限，演示必须如实显示失败/规则降级。

|时间|画面与讲述|
|---|---|
|0–15秒|打开公网产品：“这是围绕美的集团的证据研究工作台，首页初始摘要由规则生成。AI 配置状态不代表本次调用成功。”|
|15–35秒|输入“美的集团最近的利润增长是否得到了现金流支持？”；在额度可用且已私下填入口令时开始研究。展开研究过程；只有实际成功才讲真实模型完成规划与解释。429 时保留错误和降级标签，不剪辑成成功。|
|35–55秒|展示经营质量/财务趋势和结构化结论：“数字由程序计算；事实、推断和未知分开，正负证据不等于买卖信号。”|
|55–80秒|展开现金覆盖证据：报告期、原始千元值、1.42 倍代理、分子分母股东口径差异、PDF 第2页及来源链接。|
|80–100秒|加入追问上下文，输入“围绕所选现金覆盖证据，解释计算口径，并列出仍待验证的问题。”；指出所选 ID 保留。真实模型失败时说明本次追问未完成。|
|100–120秒|展示同行页和缺失估值/行情：“只有美的与格力可比财报，真实 PE/价格尚未接入，明确保留未知，不补造数据或预测。”|

录制前私下配置站点口令，画面不包含连接设置、密钥控制台、终端环境变量或私密交付文件。若截止前不能恢复额度，使用诚实的失败演示，或只提交官方允许省略的可选视频；不得把本脚本列为已录制视频。
